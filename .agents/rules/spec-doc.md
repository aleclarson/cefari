# Spec Doc Rules

Use these rules when editing `docs/spec.md`.

- Keep `docs/spec.md` focused on supported Cefari features.
- Do not make it comprehensive reference documentation.
- Avoid minutiae.
- Speak plainly.
- Use liberal bulleted lists and nested bullets.
- Keep each bullet focused on a single idea.
- Use nesting to avoid repetition.
- Add a short blockquote under each section heading that says what the section
  contains.
- Do not include implementation details unless they affect the supported
  user-facing capability.
