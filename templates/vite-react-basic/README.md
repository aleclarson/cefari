# Vite React Basic

This is a minimal Cefari project template that uses Vite and React for the frontend.

Run it from the repository root with the local Cefari build:

```bash
npm --prefix templates/vite-react-basic/frontend ci
cargo run -p cefari-cli -- dev templates/vite-react-basic
```

Build it with:

```bash
npm --prefix templates/vite-react-basic/frontend ci
cargo run -p cefari-cli -- build templates/vite-react-basic
```
